# Requisitos do Sistema

## Área do Cliente

O cliente poderá:

* visualizar os bolos disponíveis;
* visualizar preço;
* visualizar peso médio;
* visualizar quantidade disponível;
* adicionar produtos ao carrinho;
* alterar quantidade;
* escolher retirada ou entrega;
* informar seus dados;
* acompanhar o status do pedido;
* enviar o pedido para o WhatsApp.

## Área Administrativa

O administrador poderá:

* fazer login;
* cadastrar produtos;
* editar produtos;
* excluir produtos;
* ativar ou desativar produtos;
* definir quantidade disponível;
* visualizar pedidos;
* alterar status dos pedidos;
* registrar vendas manuais;
* consultar faturamento diário;
* consultar faturamento semanal;
* consultar faturamento mensal;
* consultar faturamento anual;
* filtrar faturamento por período;
* visualizar produtos mais vendidos.
