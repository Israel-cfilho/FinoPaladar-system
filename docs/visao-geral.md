# Visão Geral do Projeto

## Nome

Sistema de Vendas - Bolos de Rolo

## Objetivo

Desenvolver uma plataforma web para gerenciamento de vendas de bolos de rolo, permitindo que clientes realizem pedidos online e que a administradora gerencie produtos, pedidos, estoque disponível e faturamento.

O sistema deverá reduzir o trabalho manual realizado via WhatsApp, organizando automaticamente os pedidos antes do atendimento.

## Público

* Clientes
* Administradora da loja

## Tecnologias

### Backend

* Java 21
* Spring Boot
* Spring Security
* JWT
* Spring Data JPA
* PostgreSQL

### Frontend

* React
* TypeScript
* Tailwind CSS
* React Router
* Axios

## Objetivos principais

* Cadastro de produtos
* Controle de disponibilidade
* Carrinho de compras
* Registro automático de pedidos
* Integração com WhatsApp
* Painel administrativo
* Relatórios financeiros
* Controle de status dos pedidos
