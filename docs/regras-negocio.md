# Regras de Negócio

1. As entregas serão realizadas apenas nas cidades de Bananeiras e Solânea.

2. O cliente poderá escolher:

   * Retirada
   * Entrega

3. Caso seja retirada, nenhum endereço será obrigatório.

4. Caso seja entrega, o cliente deverá informar a cidade.

5. Se o endereço for condomínio, serão obrigatórios:

   * Nome do condomínio
   * Quadra
   * Lote

6. Se não for condomínio, serão obrigatórios:

   * Bairro
   * Rua
   * Número

7. Todo produto deverá possuir:

   * Nome
   * Descrição(opcional)
   * Preço
   * Peso médio
   * Imagem
   * Quantidade disponível

8. O pedido será salvo antes do envio ao WhatsApp.

9. O WhatsApp será aberto com a mensagem já preenchida.

10. Produtos indisponíveis não poderão ser comprados.

11. Ao criar um pedido, a quantidade disponível deverá ser reduzida.

12. Ao cancelar um pedido, a quantidade deverá retornar ao estoque.

13. Somente pedidos entregues entrarão no faturamento confirmado.

14. Apenas administradores poderão acessar o painel administrativo.
